# 🔎 Recon-Blip-X

Recon-Blip-X is an automated reconnaissance framework designed for penetration testers and bug bounty hunters to perform fast and structured target enumeration.

---

## 🚀 Features

✔ Automated Subdomain Enumeration  
✔ Live Host Detection  
✔ Port Scanning using Nmap  
✔ Organized Output for Reporting  
✔ Easy to Use for Beginners  
✔ Saves Time During Recon Phase

---

## 🛠 Tools Integrated

- Subfinder
- Assetfinder
- Amass
- Httpx
- Nmap

---

## 📂 Workflow

Recon-Blip-X follows this methodology:

1️⃣ Collect subdomains  
2️⃣ Remove duplicates  
3️⃣ Check live domains  
4️⃣ Scan open ports  
5️⃣ Export structured results
